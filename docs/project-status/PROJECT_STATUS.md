# 1. معرفی پروژه

Realestate2 یک سیستم اختصاصی معرفی و مدیریت محتوای املاک است که با Django توسعه یافته است.

هدف پروژه ساخت یک محصول حرفه‌ای برای دفاتر املاک، سازندگان پروژه‌های ساختمانی و مجموعه‌های فروش ملک است.

تمرکز اولیه:
- بازار املاک کلاردشت
- معرفی فایل‌های ملکی
- معرفی پروژه‌های ساختمانی
- معرفی مشاوران
- ایجاد اعتماد برای مشتری
