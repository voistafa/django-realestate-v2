# 1. هدف پروژه

ساخت یک سیستم اختصاصی مدیریت و معرفی املاک با Django برای دفاتر املاک حرفه‌ای، با تمرکز اولیه روی بازار کلاردشت.

هدف نهایی:
- معرفی فایل‌های ملکی
- معرفی پروژه‌های ساختمانی
- معرفی مشاوران
- ایجاد اعتماد برای خریدار
- آماده‌سازی محصول قابل ارائه به دفاتر املاک

---

# 2. وضعیت فعلی پروژه

پروژه از مرحله نمونه اولیه عبور کرده و وارد مرحله محصول قابل ارائه شده است.

وضعیت کلی:

- Backend: آماده و قابل توسعه
- Admin: سفارشی‌سازی شده
- Home: فعال و داینامیک
- Database: ساختارمند
- Git: فعال و دارای نقاط پایدار
- Deployment: هنوز انجام نشده
